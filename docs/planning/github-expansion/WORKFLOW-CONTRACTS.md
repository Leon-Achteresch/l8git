# Change workflow contracts (root ownership)

`src/lib/change-workflow/model.ts` is UI-independent. `store.ts` exports persisted `useChangeWorkflow` using platform storage. Opus owns every view and its wiring; these modules alone do not fulfill end-to-end acceptance.

- `buildChangeMap(files, dependencies)` produces stable path-keyed directory/file nodes, source-tagged dependency edges and PR/session overlays. Inputs come from actual repository trees/status/agent data; no invented dependency edges. A file has `path`, optional `size`, `pullRequests: string[]`, `sessions: string[]`. Dependency has `from`, `to`, `source: 'import' | 'manifest' | 'cochange'`; cochange is correlation, not an import. Geometry is UI-owned and should use stable IDs across filters.
- Narrative: `ReviewNarrative` holds `id`, `scope`, `pullNumber`, `title`, ordered `chapters`. Each chapter contains its explanation and `anchors` with `path`, `side`, line range, `baseSha`, `headSha`, and exact `contentFingerprint`. `chapterState(chapter, currentAnchors)` returns `current | changed | missing | unknown` and never treats missing data as proof of no change. `moveChapter` changes order by chapter ID.
- Agent evidence: `AgentEvidence` records actual `sessionId`, `task`, pinned `snapshot` (`baseSha`, `headSha`, `worktreeFingerprint`), files and explicit `checks` with command/outcome/timestamps/output summary. `evidenceState(evidence, currentSnapshot)` returns `current | stale | unknown`; changed worktree or revisions invalidate evidence. UI must derive snapshots from real backend data and record real checks, never a manually selected green badge.
- Multi-repo: `ChangeInitiative` contains `id`, name, `steps` with repo/branch/pinned head/optional PR URL, dependency IDs and status (`pending | running | done | failed`). `planInitiative` validates dependency identities and cycles, returns deterministic topological order and readiness. `transitionInitiative` gates starting on dependencies, permits resumption of failures, and prevents changing a completed dependency while completed/running dependents still rely on it. It coordinates separate operations; no atomic cross-repo claim.
- Scope helpers serialize `[provider, host, login, repository]` without delimiter collisions; scope is provided by caller from selected account/repository.
- `useChangeWorkflow` provides scoped `saveNarrative/removeNarrative`, `recordEvidence/removeEvidence`, `saveInitiative/removeInitiative`. No secrets in persisted state.

Verification: focused `src/lib/change-workflow/model.test.ts` tests. IDs 71/72/74/75 remain integration-pending until real UI and data sources are wired and tested.

`readers.ts` connects actual data: `loadChangeMap(path, overlays, dependencies)` uses `repo_list_files` and `repo_status`, keeps deleted overlay files navigable and returns the map. This is explicitly a working-copy map. `captureAgentSnapshot(worktreePath, basePath)` reads both heads and review-content fingerprints, rejects observed races, returns `{snapshot, files}`. `runWithEvidence(worktreePath, basePath, runCallback)` captures before/after, calls an explicit caller-owned runner, and returns `{result, startedAt, finishedAt, snapshot, files, state}`; a passing check with worktree changes is stale. All readers allow an explicit `AgentReviewInvoke` for host-scoped calls/tests.

`dependencies.ts`: `sourceDependencies(documents: {path,text}[], repositoryPaths: string[])` returns `{dependencies, unresolved, unsupported: string[], supported: 'static-relative-js-ts-without-jsx'}`. This is a deliberately bounded static JS/TS relative import/export/require subset. **JSX/TSX documents are explicitly excluded** until a JSX-aware parser is supported: rendered JSX text must not become a false import edge. They may still be legitimate targets of imports from supported source files. UI must display excluded paths/counts. Comments, strings and computed/template specifiers are omitted; packages, aliases, TypeScript extension substitution and other languages are not resolved. Edges reference only actual known repository paths and preserve `source: 'import'`. Display limits and unresolved counts; absence of an edge does not establish absence of a dependency. Bounded `source_files` reads and actual dirty-worktree `evidence_run` are implemented; canonical request union is in `git-expansion/index.ts`.
